# Stellar Burgers – интернет-магазин для заказа бургеров

Полнофункциональное веб-приложение для конфигурации и заказа бургеров с системой аутентификации, управлением профилем и фидом заказов в реальном времени.

## Ключевые функции

### Конструктор бургеров
- Интерактивный конструктор с drag-and-drop функциональностью
- Каталог ингредиентов с группировкой по категориям (булки, начинки, соусы)
- Реальное время расчета цены
- Модальные окна с деталями ингредиентов
- Автоматическое очищение конструктора после успешного заказа

### Система аутентификации
- Регистрация новых пользователей
- Вход в личный кабинет
- Восстановление пароля с отправкой кода на почту
- Система refresh-токенов для безопасного хранения сессии
- Защищенные маршруты с проверкой прав доступа

### Личный кабинет
- Просмотр истории заказов
- Редактирование профиля пользователя (имя, email, пароль)
- Детальная информация о каждом заказе с составом и временем доставки
- Синхронизация данных между вкладками

### Фид заказов
- Просмотр всех заказов в реальном времени
- Фильтрация по статусу (выполнены/готовы/в работе)
- Детальное отображение информации о заказе в модальном окне
- Статистика по выполненным заказам и очереди

## Запуск проекта

### Требования
- Node.js (v16 или выше)
- npm или yarn

### Установка зависимостей
```bash
npm install
```

### Разработка
Запуск сервера разработки на `http://localhost:8080`:
```bash
npm start
```

### Построение для продакшена
```bash
npm run build
```

### Запуск тестов

**Unit-тесты (Jest):**
```bash
npm test
```

**E2E-тесты (Cypress):**
```bash
npm run cypress:open
```

### Документация компонентов
Запуск Storybook на `http://localhost:6006`:
```bash
npm run storybook
```

### Zusätzliche команды
- `npm run lint` – проверка кода ESLint
- `npm run lint:fix` – автоисправление стилистических ошибок
- `npm run format` – форматирование кода Prettier

## Структура проекта

```
src/
├── components/       # Переиспользуемые компоненты (Header, Modal, Burger Constructor и т.д.)
├── pages/           # Страницы приложения (Constructor, Feed, Profile, Auth)
├── services/        
│   ├── slices/      # Redux Toolkit слайсы для управления состоянием
│   ├── rootReducer.ts
│   └── store.ts
├── utils/           # Утилиты для работы с API, cookies и типы
└── stories/         # Storybook истории для компонентов
```

## Стек технологий

**Frontend:**
- **React 18** – библиотека для создания UI
- **TypeScript** – типизированный JavaScript
- **Redux Toolkit** – управление глобальным состоянием приложения
- **React Router v6** – маршрутизация между страницами
- **Webpack 5** – сборка приложения
- **SCSS** – препроцессор для стилей

**UI & Design:**
- **React Developer Burger UI Components** – готовая UI библиотека для компонентов
- **Figma** – дизайн-макеты приложения

**Тестирование:**
- **Jest** – unit-тесты с покрытием компонентов и функций
- **Cypress** – E2E тесты с проверкой пользовательских сценариев

**Documentation:**
- **Storybook** – интерактивная документация компонентов

**Developer Tools:**
- **ESLint** – анализ и контроль качества кода
- **Prettier** – форматирование кода
- **babel** – transpilation TypeScript и JSX

Проект включает comprehensive тесты:
